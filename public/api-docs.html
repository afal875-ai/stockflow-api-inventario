Catálogo de servicios

GET/healthComprueba la disponibilidad del servicio.
GET/productsLista, busca y filtra productos.
GET/products/{id}Consulta un producto por identificador.
POST/productsRegistra una nueva referencia.
PUT/products/{id}Actualiza uno o varios datos del producto.
PATCH/products/{id}Actualiza parcialmente un producto.
DELETE/products/{id}Elimina una referencia del catálogo.
GET/products/summaryCalcula indicadores consolidados.
GET/products/categoriesDevuelve las categorías registradas.
POST/products/{id}/movementsRegistra una entrada o salida de unidades.
GET/products/{id}/movementsConsulta el historial de una referencia.
GET/movementsConsulta y filtra todos los movimientos.
